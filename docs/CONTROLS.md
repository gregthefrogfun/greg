# Controls

Click the world to start flying. Press **Esc** to get your mouse back for menus.

| Key | Action |
|---|---|
| Mouse | Look and steer |
| W A S D | Fly, or walk when landed |
| Space | Up |
| Ctrl | Down |
| Shift | Boost (uses stamina) |
| Double-tap A / D | Dodge-roll |
| E | Rub hands |
| F | Interact |
| C | Land on anything, or take off |
| V | First / third person |
| B | Fly Eyes 360 (compound-eye vision) |
| M | Map |
| T or Enter | Chat |
| Z / X | Left / right front leg |
| Q / R | Left / right wing |
| 1 to 4 | Emotes |
| H | Hide the controls card |

**Skill mode** (in settings): flap each wing separately with the left and right mouse buttons. Uneven flaps roll you. Hard to learn, satisfying to master.

**Phones:** joystick plus on-screen buttons. Tap **?** to see everything.
