# Security

No keys, secrets, or private source live in this repository.

If you find a security issue with gregthefrog.fun, Greg's wallet integration, or anything related, please report it privately via a direct message to [@gregthefrogfun](https://x.com/gregthefrogfun) instead of opening a public issue.

Greg will never DM you first asking for your wallet, seed phrase, or private key. Anyone who does is not Greg.
